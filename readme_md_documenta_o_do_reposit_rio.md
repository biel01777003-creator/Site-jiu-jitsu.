# 🥋 BJJ Master Pro — Academia Digital & Quiz Interativo

Plataforma web interativa dedicada ao **Jiu-Jitsu Brasileiro (BJJ)**, com desafios baseados nas regras oficiais da **IBJJF**, história da Arte Suave, finalizações e sistemas de pontuação.

## ✨ Funcionalidades
- **3 Modalidades de Luta:** Campeonato (Clássico 25s), Blitz (12s com XP em dobro) e Morte Súbita (1 vida).
- **Temas por Faixa:** Alterne a interface entre Branca, Azul, Roxa, Marrom e Preta.
- **Certificado Oficial:** Geração automática de certificado com faixa conquistada, precisão, combo máximo e opção de compartilhamento.
- **Efeitos Sonoros Nativos:** Áudio sintetizado via Web Audio API sem necessidade de arquivos externos.
- **Salvamento de Recorde:** Armazenamento local automático (`localStorage`) da maior pontuação.

## 🚀 Como publicar no GitHub Pages
1. Faça o upload dos arquivos `index.html`, `style.css`, `script.js` e `README.md` na raiz do seu repositório no GitHub.
2. Acesse **Settings** → **Pages** no menu do repositório.
3. Em **Branch**, escolha `main` e clique em **Save**.
4. Aguarde alguns segundos e acesse o link gerado pelo GitHub!
